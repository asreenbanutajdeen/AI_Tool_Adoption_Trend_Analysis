# AI Tool Adoption Trend Analysis

## Project Overview
This project analyzes AI adoption trends across organizations using statistical techniques and data visualization.

## Objectives
- Identify popular AI tools
- Analyze industry adoption patterns
- Study company size impact
- Perform hypothesis testing
- Generate business recommendations

## Dataset Features
- Country
- Industry
- AI Tool
- Adoption Rate
- Daily Active Users
- User Feedback
- Company Size

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## Analysis Performed
1. Data Cleaning
2. Descriptive Statistics
3. Trend Analysis
4. Correlation Analysis
5. Hypothesis Testing
6. Organization Segmentation

## Key Findings
- ChatGPT showed highest adoption.
- Company size influenced AI adoption.
- Higher investment led to higher savings.
